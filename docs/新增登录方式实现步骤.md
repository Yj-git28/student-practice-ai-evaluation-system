# 新增登录方式实现步骤（A：手机号登录 / B：短信验证码登录）

- 项目：`student-practice-ai-evaluation-system`
- 技术栈：Spring Boot 4.1.1 + JdbcClient + Spring Security + JWT；Vue 3 + Pinia + Element Plus
- 适用版本：当前已支持「用户名 + 密码」登录（`POST /api/auth/login`）
- 实现顺序：先做第 0 步重构，再做 A，最后做 B（B 依赖 A 的 `phone` 字段）

---

## 0. 前置重构：拆分 AuthService

**目的**：把「验证身份」与「签发 token」解耦，后续任何登录方式只需写验证逻辑。

文件：`backend/src/main/java/org/example/backend/auth/AuthService.java`

改造前：

```java
public LoginVO login(LoginDTO dto) {
    SysUser user = userMapper.selectByUsername(dto.getUsername())
            .orElseThrow(() -> new BizException(4001, "用户名或密码错误"));
    if (!passwordEncoder.matches(dto.getPassword(), user.getPassword())) {
        throw new BizException(4001, "用户名或密码错误");
    }
    LoginUser lu = permissionService.buildLoginUser(user.getUserId());
    String token = jwtService.createToken(lu.getUserId(), lu.getUsername(), lu.getRoleCode());
    return new LoginVO(token, jwtService.getExpireSeconds());
}
```

改造后：

```java
public LoginVO login(LoginDTO dto) {
    SysUser user = userMapper.selectByUsername(dto.getUsername())
            .orElseThrow(() -> new BizException(4001, "账号或密码错误"));

    if (!passwordEncoder.matches(dto.getPassword(), user.getPassword())) {
        throw new BizException(4001, "账号或密码错误");
    }
    return issueToken(user);
}

/** 所有登录方式共用：组装 LoginUser + 签发 JWT */
private LoginVO issueToken(SysUser user) {
    LoginUser lu = permissionService.buildLoginUser(user.getUserId());
    String token = jwtService.createToken(lu.getUserId(), lu.getUsername(), lu.getRoleCode());
    return new LoginVO(token, jwtService.getExpireSeconds());
}
```

验收：改完先编译一次，原有用户名密码登录仍然可用。

### A-2 后端：Mapper 增加按手机号查询

```java
/** 手机号登录。status / deleted 为新增列，一并加上过滤 */
public Optional<SysUser> selectByPhone(String phone) {
    return jdbc.sql("""
            SELECT user_id, username, password, real_name, role_id, class_id
            FROM sys_user
            WHERE phone = :phone AND status = 1 AND deleted = 0
            """)
            .param("phone", phone)
            .query(SysUser.class)
            .optional();
}
```

同时把已有的 `selectByUsername` 补上状态过滤：

```sql
WHERE username = :username AND status = 1 AND deleted = 0
```

## B. 短信验证码登录

### B-1 数据库：验证码表

```sql
CREATE TABLE sys_login_code (
  id          BIGINT       NOT NULL AUTO_INCREMENT,
  target      VARCHAR(64)  NOT NULL COMMENT '手机号',
  code        VARCHAR(8)   NOT NULL,
  expire_at   DATETIME     NOT NULL,
  used        TINYINT      NOT NULL DEFAULT 0,
  create_time DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP,
  PRIMARY KEY (id),
  KEY idx_target_time (target, create_time)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='短信登录验证码';
```

> 若已有 Redis，可改为 `SETEX sms:{phone} 300 {code}`，无需建表。

### B-2 后端：新增 Mapper

新文件：`backend/src/main/java/org/example/backend/auth/LoginCodeMapper.java`

```java
package org.example.backend.auth;

import org.springframework.jdbc.core.simple.JdbcClient;
import org.springframework.stereotype.Repository;

@Repository
public class LoginCodeMapper {

    private final JdbcClient jdbc;

    public LoginCodeMapper(JdbcClient jdbc) {
        this.jdbc = jdbc;
    }

    public void save(String phone, String code, int expireSeconds) {
        jdbc.sql("""
                INSERT INTO sys_login_code(target, code, expire_at)
                VALUES (:t, :c, DATE_ADD(NOW(), INTERVAL :s SECOND))
                """)
                .param("t", phone).param("c", code).param("s", expireSeconds)
                .update();
    }

    /** 校验并消费：仅未使用且在有效期内的验证码可命中 */
    public boolean verifyAndConsume(String phone, String code) {
        int n = jdbc.sql("""
                UPDATE sys_login_code SET used = 1
                WHERE target = :t AND code = :c AND used = 0 AND expire_at > NOW()
                ORDER BY id DESC LIMIT 1
                """)
                .param("t", phone).param("c", code)
                .update();
        return n > 0;
    }

    /** 指定秒数内是否已发送过，用于 60 秒限流 */
    public int countRecent(String phone, int seconds) {
        Integer c = jdbc.sql("""
                SELECT COUNT(1) FROM sys_login_code
                WHERE target = :t AND create_time > DATE_SUB(NOW(), INTERVAL :s SECOND)
                """)
                .param("t", phone).param("s", seconds)
                .query(Integer.class).single();
        return c == null ? 0 : c;
    }
}
```

### B-4 后端：Service 增加两个方法

在 `AuthService` 中注入 `LoginCodeMapper`，并追加：

```java
public void sendLoginCode(String phone) {
    if (phone == null || !phone.matches("^1[3-9]\\d{9}$")) {
        throw new BizException(4002, "手机号格式不正确");
    }
    if (codeMapper.countRecent(phone, 60) > 0) {
        throw new BizException(429, "发送过于频繁，请 60 秒后再试");
    }
    if (userMapper.selectByPhone(phone).isEmpty()) {
        throw new BizException(4004, "该手机号未绑定账号");
    }

    String code = String.valueOf(ThreadLocalRandom.current().nextInt(100000, 1000000));
    codeMapper.save(phone, code, 300);

    // 演示环境：输出到日志；上线时替换为短信服务商 SDK 调用
    log.info("[SMS-MOCK] phone={} code={}", phone, code);
}

public LoginVO loginBySms(SmsLoginDTO dto) {
    if (!codeMapper.verifyAndConsume(dto.getPhone(), dto.getCode())) {
        throw new BizException(4001, "验证码错误或已过期");
    }
    SysUser user = userMapper.selectByPhone(dto.getPhone())
            .orElseThrow(() -> new BizException(4004, "该手机号未绑定账号"));
    return issueToken(user);
}
```

`log` 使用 Lombok 的 `@Slf4j`（项目已引入）。

### B-5 后端：Controller 增加两个接口

文件：`backend/src/main/java/org/example/backend/auth/AuthController.java`

```java
@PublicApi
@PostMapping("/sms/send")
public R<Void> sendSms(@RequestBody SmsLoginDTO dto) {
    authService.sendLoginCode(dto.getPhone());
    return R.ok(null);
}

@PublicApi
@PostMapping("/login/sms")
public R<LoginVO> loginBySms(@RequestBody SmsLoginDTO dto) {
    return R.ok(authService.loginBySms(dto));
}
```

> **必须标注 `@PublicApi`**，否则 `PermissionCoverageChecker` 会在启动时报「接口未登记权限」并终止启动。

### B-8 前端：Login.vue 改为双 Tab

文件：`frontend/src/views/Login.vue`

```vue
<template>
  <div style="display:flex;justify-content:center;align-items:center;height:100vh;background:#f5f5f5;">
    <el-card style="width:420px;padding:20px;">
      <h2 style="text-align:center;margin-bottom:24px;">软件实训AI检查评价系统</h2>

      <el-tabs v-model="tab">
        <el-tab-pane label="账号登录" name="pwd">
          <el-form :model="form" @keyup.enter="handleLogin">
            <el-form-item label="账号">
              <el-input v-model="form.username" placeholder="用户名 / 手机号" />
            </el-form-item>
            <el-form-item label="密码">
              <el-input v-model="form.password" type="password" show-password />
            </el-form-item>
          </el-form>
        </el-tab-pane>

        <el-tab-pane label="验证码登录" name="sms">
          <el-form :model="sms" @keyup.enter="handleSmsLogin">
            <el-form-item label="手机号">
              <el-input v-model="sms.phone" placeholder="11 位手机号" />
            </el-form-item>
            <el-form-item label="验证码">
              <div style="display:flex;gap:8px;width:100%">
                <el-input v-model="sms.code" placeholder="6 位验证码" />
                <el-button :disabled="countdown > 0" @click="handleSendCode">
                  {{ countdown > 0 ? countdown + 's' : '获取验证码' }}
                </el-button>
              </div>
            </el-form-item>
          </el-form>
        </el-tab-pane>
      </el-tabs>

      <el-button type="primary" style="width:100%;margin-top:8px" :loading="loading"
                 @click="tab === 'pwd' ? handleLogin() : handleSmsLogin()">
        登录系统
      </el-button>
    </el-card>
  </div>
</template>

<script setup>
import { ref } from 'vue'
import { useRoute, useRouter } from 'vue-router'
import { useUserStore } from '@/stores/useUserStore'
import { ElMessage } from 'element-plus'

const router = useRouter()
const route = useRoute()
const userStore = useUserStore()

const tab = ref('pwd')
const loading = ref(false)
const countdown = ref(0)
const form = ref({ username: '', password: '' })
const sms = ref({ phone: '', code: '' })

async function afterLogin() {
  const redirect = route.query.redirect || '/'
  await router.replace(redirect)
}

const handleLogin = async () => {
  if (!form.value.username || !form.value.password) {
    return ElMessage.warning('请输入账号和密码')
  }
  loading.value = true
  try {
    await userStore.login(form.value)
    await afterLogin()
  } catch (e) {
    ElMessage.error(e.message || '登录失败')
  } finally {
    loading.value = false
  }
}

const handleSendCode = async () => {
  if (!/^1[3-9]\d{9}$/.test(sms.value.phone)) {
    return ElMessage.warning('请输入正确的手机号')
  }
  try {
    await userStore.sendSmsCode(sms.value.phone)
    ElMessage.success('验证码已发送，请查看后端日志')
    countdown.value = 60
    const timer = setInterval(() => {
      countdown.value--
      if (countdown.value <= 0) clearInterval(timer)
    }, 1000)
  } catch (e) {
    ElMessage.error(e.message || '发送失败')
  }
}

const handleSmsLogin = async () => {
  if (!sms.value.phone || !sms.value.code) {
    return ElMessage.warning('请输入手机号和验证码')
  }
  loading.value = true
  try {
    await userStore.loginBySms(sms.value)
    await afterLogin()
  } catch (e) {
    ElMessage.error(e.message || '登录失败')
  } finally {
    loading.value = false
  }
}
</script>
```

需要覆盖的边界场景：

| 场景 | 预期 |
|---|---|
| 60 秒内重复发送 | 429「发送过于频繁」 |
| 验证码错误 | 4001「验证码错误或已过期」 |
| 同一个验证码使用两次 | 第二次失败（已消费） |
| 验证码超过 5 分钟 | 失败 |
| 未绑定手机号 | 4004「该手机号未绑定账号」 |
| 账号 `status = 0` | 登录失败 |

## 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 应用启动失败，提示接口未登记权限 | 新接口漏标 `@PublicApi` | 补注解 |
| 新登录接口返回 401 | `SecurityConfig` 未放行 | 加入 `permitAll` |
| 前端提示跨域失败 | 实际是 401 被浏览器识别为 CORS 错误 | 先查后端是否放行 |
| 登录成功但菜单为空 | 未走 `buildLoginUser` | 统一调用 `issueToken()` |
| 手机号登录提示账号不存在 | `phone` 未写入或存在空格 | `SELECT phone FROM sys_user` 检查 |
